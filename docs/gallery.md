# The Gallery: the tutorial room

Room GF.06 of Casa Monarch (`data/ground_floor.json`, x 0.3-4.9, y 4.2-8.2) holds one exhibit
per way of getting an object into the model. Every exhibit is an ordinary element with full
metadata plus a `gallery` block that becomes `Pset_Gallery` (Title, Provenance, License, HowTo,
Prompt) in the IFC, so any viewer shows the lesson on click; `web/` and `site/` draw the titles
as floating labels (Plaques toggle). Next to each exhibit hangs a plaque: a 0.30 x 0.02 x 0.20 m
board at 1.5 m whose front carries a PNG with the same text.

Everything is authored once in `data/gallery.json`. `uv run python src/gen_plaques.py` renders
the PNGs into `assets/plaques/` (PyMuPDF, 600 x 400 px) and writes the plaque boards and the
`gallery` blocks into the data; `--check` reports stale data without writing. Run it after
editing the text, then `./build.sh`.

## The prompts on the plaques

Each one works in this repository with the `model-change` and `find-asset` skills:

1. Add a 0.8 x 0.4 x 2.0 m bookshelf with five shelves on the north wall of the study
2. Place a second demo-bookshelf in the living room with ./place
3. Generate a 0.5 m tall spiral vase with src/gen_assets.py and put it on the sideboard in the living room
4. Find a CC0 vase on Poly Haven and place it on the dining table
5. Find a CC-BY teapot on Sketchfab, convert it with src/convert_asset.py and credit the author in the props
6. Hang a 60 x 41 cm print of assets/picture_great_wave.jpg above the bed
7. Switch the gallery centre to the sculpture variant
8. Add a clear rule that keeps 90 cm in front of the bedroom wardrobe free
9. Find a CC0 plant on Poly Haven and put it on the empty plinth in the gallery

## Try the rule (exhibit 8)

Move `GAL_PLINTH_EMPTY` 20 cm south (y 7.15 -> 6.95 in both boxes) and run `./build.sh`:

```
FAIL  gallery:gallery-walkway-clear  GAL_PLINTH_EMPTY enters the zone (0.450 x 0.050 x 0.900 m overlap of bounds)
```

## Adding an exhibit

1. Model the element in `data/ground_floor.json` (or as a product / variant) with the usual
   metadata (`Product`, `Supplier`, `SourceURL`, `Dimensions`, `License`, `Status`).
2. Append an entry to `data/gallery.json`: `key` (file name of the PNG), `element` (id, list of
   ids, product id, or `null` to put the Pset_Gallery on the plaque itself), the five texts and
   `plaque: {at: [x, y], normal: [nx, ny]}`, the board centre on the wall face and the direction
   into the room.
3. `uv run python src/gen_plaques.py && ./build.sh`, then look at it:
   `.venv/bin/python src/snap_web.py gallery room=GAL_`.

Where a plaque hangs: on the wall behind or beside the exhibit, 1.5 m above the floor, never in
a door swing or in front of a window (the gallery windows start at 1.7 m for that reason).
